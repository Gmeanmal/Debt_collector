14

Accessibility

All text meets WCAG AA. Focus rings visible. Keyboard-navigable everywhere. Icons-as-controls carry aria-label.

  • Contrast ratio ≥ 4.5:1 for body text against its background
  • All interactive elements get a 3px focus ring (pink @ 33% alpha)
  • Modals trap focus; Esc closes
  • Live regions (role="status") on updating counters
  • prefers-reduced-motion disables pulse / glow animations
